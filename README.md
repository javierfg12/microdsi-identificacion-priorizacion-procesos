# MicroDSI — Microlearning de identificación y priorización de procesos

Aplicación web educativa para trabajar los contenidos de M2-S10 mediante tres itinerarios: ITSM Triage, HR y Procurement.

## Funcionalidades
- Feed de microlecciones con ejemplos adaptados al track seleccionado.
- Caso guiado con pistas y preguntas de reflexión.
- Laboratorio para crear inventario L1, priorización y SIPOC.
- Exportación del entregable en Markdown.
- Persistencia local del track, las marcas y las respuestas del caso mediante `localStorage`.

## Ejecución
No requiere instalación ni servidor backend. Abre `index.html` en un navegador moderno o publica el repositorio con GitHub Pages.

## Navegación
- `index.html`: portada.
- `feed.html`: microlecciones.
- `pista.htm`: caso guiado.
- `lab.html`: laboratorio y exportación.

## Datos y privacidad
El progreso se guarda únicamente en el almacenamiento local del navegador. No introduzcas información personal ni confidencial.

## Tecnologías
HTML5, CSS3 y JavaScript vanilla.
